# Security policy

ChatHarbor is currently at the design stage. Please do **not** upload real WhatsApp exports, administrator phone numbers, invitation URLs, encryption keys, or personal data to public issues or pull requests.

For a suspected security vulnerability, contact the maintainers privately through GitHub's private vulnerability reporting feature if enabled, or request a private reporting channel without disclosing exploit details publicly.

Principles:
- Local-first and explicit consent to import.
- Encrypt sensitive data at rest where supported.
- Preserve originals, verify hashes, and clearly label incomplete exports.
- Never ask for WhatsApp credentials or bypass account restrictions.
- Do not claim recovered group membership without user-side confirmation.

This repository and its static GitHub Pages website do not accept chat data uploads.
